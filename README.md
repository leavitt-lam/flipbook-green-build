# PDF To Flipbook Studio v3.7.0

本地 PDF 交互画册生成器，用于将 PDF 转换为可检索、可跳转、适合电脑与安卓平板离线阅读的交互画册。v3.7.0 在 v3.6 的识别和渲染基础上加入 Windows 稳定运行层/可更新工具层、自适应文字清晰度，以及保留原版 HTML 的安卓离线 PWA 桌面包。

## v3.7 新增

- 进度条动画严格限制在边框内。
- “自适应均衡”默认根据 Android 设备内存和屏幕倍率温和提高画布采样精度；另有流畅优先、清晰优先。
- 一次生成两个结果：原版画册 ZIP 与安卓离线桌面包。安卓包使用外置 PDF，避免大体积 Base64 的解码和内存峰值。
- Windows 绿色版采用 `runtime/` + `tool/` 两层结构。Python、PDFium、PyMuPDF、Pillow、NumPy 固定在 runtime；以后只更新 tool。
- 默认数字识别是内置的画册字形自学习 OCR；Tesseract 仅为可选备用，不会因为没看到 Tesseract 进程就表示 OCR 没加载。

## 推荐启动方式

源码版 Windows 双击最外层的 `启动增强生成器.bat`。真正绿色完整版双击 `启动生成器.bat`，它只调用内置 runtime，绝不在线安装；若 runtime 缺失会直接报错。

macOS / Linux：

```bash
./start-enhanced.sh
```

仅双击 `index.html` 仍可进入浏览器基础模式，但不会自动压缩、识别转轮廓页码或生成独立兼容页。

## 本版如何处理三个核心问题

### 第 2 / 第 6 页

- 主体仍保留 PDF，普通页由 PDF.js 动态渲染，文字可选，缩放后重绘。
- 增强服务分析页面的绘图组、图片数和复杂度，自动标记高风险渐变/混合页。
- 仅高风险页由独立 PDFium 引擎渲染为高分辨率 WebP，自动嵌入画册，无需逐页导图和上传。
- 当前样本自动识别第 1、2、6 页；第 2 页不再出现网格裂缝，第 6 页使用正确的浅蓝混合结果。

### 目录框边界

- 不再从产品名行距推算上边缘，也不再用名称/页码文字宽度猜右边缘。
- 增强服务直接读取 PDF 绘图层中成组、尺寸一致的卡片矩形。
- 以原始矩形框线为基准，上、右、左、下都增加约 3pt 的一致视觉余量，整列边缘保持对齐。
- 本样本稳定识别 46 个卡片矩形。

### 跳转页码

- 本样本的 46 个目录页码中，45 个已经转成矢量轮廓，PDF 文本层无法读取；这是旧版只有约 30–40% 正确率的根因。
- 增强服务先从画册自身页脚自动学习 0–9 的实际字形，再识别卡片下方的轮廓页码；字体随画册自适应，不要求 Windows 另装 Tesseract。
- 得到印刷页码后，用全书页脚拟合“印刷页码 → PDF 物理页”的稳定关系。
- 本样本在禁用 Tesseract 的情况下验证为 46/46 个页码识别、46 个不同目标页全部映射成功。
- 浏览器基础模式取消了高风险的“整页关键词兜底”；规格密集页不会再把多个产品集中吸到同一页（此前常见为第 52 页）。没有可靠标题或完整名称时宁可留空等待确认。

### 缩略图与缩放

- 编辑器和生成画册的异常页缩略图使用 PDFium 兼容图，因此第 6 页缩略图与大图一致。
- 缩略图按 PDF 页面的真实宽高比布局；横版画册显示横版缩略图，不再强制拉伸成竖版。
- 放大按钮循环切换 `1.5× → 2× → 3× → 1.5×`，旁边恢复按钮回到 `1×`。
- 安卓平板可单指拖动、双指缩放；电脑可按住鼠标左键拖动画面。停止操作后按当前倍率高清重绘。

## 压缩档位

| 档位 | 正常页 PDF | 自动兼容页 | 用途 |
|---|---:|---:|---|
| 平板均衡（默认） | 约 150dpi 位图资源 | 2600px WebP | 安卓平板、日常分发 |
| 高清 | 约 180dpi | 3000px WebP | 大屏和更高倍率查看 |
| 小体积 | 约 110dpi | 2000px WebP | 网络分发、低存储设备 |
| 原始 PDF | 不改 PDF | 2600px WebP | 不希望压缩源资源 |

压缩只重采样 PDF 内的高分辨率位图，文字、线稿和大部分矢量对象继续保留。若检测到 Ghostscript，会优先使用其高效压缩；否则使用 PyMuPDF 便携压缩。生成器本身体积不影响最终画册体积。

## 文字清晰度

查看器仍由 PDF.js 把页面绘制到 Canvas，因此屏幕上不是浏览器原生 SVG 字形；透明文字层用于选择和搜索。默认“自适应均衡”在内存不少于 6GB 的 Android 平板提高采样倍率和像素上限，低内存设备自动保守。完整 SVG 化会显著增加 DOM、字体兼容和复杂页错误风险，当前不作为默认路径。

## 安卓完全本地桌面包

生成完成后点击“下载安卓离线桌面包”。包内含 `index.html`、`catalog.pdf`、`manifest.webmanifest`、`sw.js` 和图标。把文件夹复制到平板，用本机静态 HTTP 服务器从 `127.0.0.1` 打开，再由 Edge 添加到桌面；整个浏览和翻页过程无需互联网。

Android Edge 不能把 `file://` 文件直接安装为桌面 PWA，这是浏览器安全模型限制，不是画册代码故障。若要完全免本机服务器，最终形式只能是 APK/WebView 外壳；工程可在具备 Android SDK 的机器上再编译。

## 目录结构

```text
PDF_To_Flipbook_Studio_v3.7.0/
├─ index.html                 生成器入口（最外层）
├─ 启动增强生成器.bat        Windows 推荐入口
├─ start-enhanced.sh          macOS / Linux 入口
├─ enhanced_server.py         本机增强服务
├─ app.js / detect.js         构建产物
├─ src/                       可维护源码
├─ libs/                      pdf.js 与 JSZip
├─ tests/                     自动测试
├─ build.mjs
├─ runtime_bootstrap.py       固定运行层入口，动态执行 tool 中的新代码
├─ build_windows_portable.bat Windows 绿色完整版构建脚本
├─ 绿色版/                    绿色版启动、更新脚本与说明
└─ requirements.txt
```

发布包最外层就是生成器，不含 `dist/`、`_legacy/`、备份目录或重复版本。

## 可选依赖

- Tesseract：仅作为少数特殊字体/标签版式的备用 OCR；常规页码由画册自身数字字形完成识别，无需安装。
- Ghostscript：用于更高效的 PDF 位图压缩。未安装时自动使用 PyMuPDF。
- PDFium 已由 `pypdfium2` 提供，是第 2 / 第 6 页兼容层的默认渲染器。

在联网的 Windows 构建机上运行一次 `build_windows_portable.bat` 会生成完整绿色包；最终用户机器无需 Python、pip 或网络。也可以在构建前把 Ghostscript 放入 `tools/ghostscript/`，把便携 Tesseract 放入 `tools/tesseract/`，脚本会一并打包。

## 构建与测试

```bash
node build.mjs
npm test
node tests/viewer.acceptance.mjs
```

验收重点：增强服务状态必须显示“PDFium 独立兼容渲染”和“自学习页码识别”；目录页应为 46 个矢量框且 46 个目标页已设置；第 2、6 页的大图和缩略图都应显示自动兼容图；横版缩略图不得变形；缩放三档均可拖动；生成 ZIP 的 PDF 体积应与所选压缩档一致。
